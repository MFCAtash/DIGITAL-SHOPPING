# اصول طراحی Digital Shopping (یک‌صفحه)

جهت بصری: **«برگهٔ مشخصات»** — کاغذ گرم، جوهر تیره، یک رنگ سیگنال. تصمیم و دلایل: [ADR-002](../../../docs/adr/0002-design-direction.md).

## هویت در یک نگاه
1. **خریدار الکترونیک مقایسه می‌کند.** پس صفحه مثل برگهٔ فنی دقیق است: تایپوگرافی‌محور، خط نازک، عدد هم‌عرض.
2. **یک رنگ سیگنال** (`--cx-signal`) فقط برای **قیمت** و **CTA اصلی**. هر چیز دیگر جوهر/خاکستری.
3. **طلای برند** فقط در نشان/لوگو و الگوی شمسه؛ هرگز متن (کنتراست کافی ندارد و در توکن‌ها جفت متنی ندارد).
4. **رنگ تطبیقی (جهت C)** فقط روی چند عنصر صفحهٔ محصول: خط زیر عنوان و نشان واریانت. هرگز دکمهٔ خرید یا قیمت.

## قواعد «ضد ظاهر AI» (CI اجرا می‌کند: `npm run lint:design`)
| قاعده | اجرا |

| شعاع گوشه ۰ تا ۴px (۵۰٪/pill فقط سوییچ و نقطه) | لینتر |
| بدون ایموجی؛ آیکون خطی یک‌ضخامت | لینتر + `<Icon/>` |
| فقط رنگ توکن؛ رنگ هگز خام در CSS ممنوع | لینتر |
| فقط ویژگی منطقی (`inline-start/end`) برای RTL | لینتر |
| بدون Inter / Space Grotesk / Poppins | لینتر |
| بدون هیرو وسط‌چین با تیتر گرادیانی؛ بدون ردیف سه‌تایی «آیکون+تیتر+متن» | بازبینی طراحی (PR) |
| چینش نامتقارن (۷/۵ در صفحهٔ محصول) نه کارت‌های هم‌اندازهٔ تکراری | بازبینی طراحی |

## رنگ
توکن‌ها در `src/tokens/tokens.ts` (منبع یگانه) → `tokens.css` تولیدشده. **همهٔ ۳۸ جفت متن/پس‌زمینه** در `npm run contrast` سنجیده می‌شود (متن اصلی ≥ ۷:۱، بقیه ≥ ۴٫۵:۱، مرز کنترل و فوکوس ≥ ۳:۱). رنگ حالت (موجود/هشدار/خطا) **هرگز تنها** نیست: آیکون یا متن هم دارد.
تم تاریک طراحی جدا دارد (گرافیت `#141517`، نه سیاه خالص).

## تایپوگرافی فارسی
- پشته: لاتین (IBM Plex) اول، فارسی بعد؛ حروف و ارقام فارسی خودکار از فونت فارسی می‌آیند.
- ارتفاع خط متن فارسی ۱٫۹؛ `letter-spacing: 0` (اتصال حروف می‌شکند)؛ کشیده‌نویسی تزئینی نه.
- اعداد جدولی (`.cx-num`) برای قیمت و مشخصات.
- نام مدل‌های لاتین داخل متن فارسی در `<bdi>` (همهٔ مقادیر SpecTable و CompareTable خودکار).
- تومان: «۱۲٬۵۰۰٬۰۰۰ تومان»؛ تاریخ شمسی با `formatJalali`.

## عکس محصول
پس‌زمینهٔ سفید و نورپردازی یکدست؛ در صحنهٔ `--cx-media` با `mix-blend-mode: multiply` حل می‌شود (هر دو تم). ابعاد `width/height` همیشه مشخص (CLS صفر). عکس تزئینی `alt=""` است چون عنوان کنارش همان را می‌گوید.

## حرکت
هدفمند و کوتاه (۱۲۰ تا ۳۲۰ms)، فقط رنگ/حاشیه/چرخش آیکون. `prefers-reduced-motion` همه را خاموش می‌کند. اسکلت بارگذاری هم‌شکل چیدمان واقعی است و فقط opacity می‌تپد (بدون shimmer گرادیانی).

## دسترس‌پذیری (حداقل‌ها)
- هدف لمسی ≥ ۴۴px (تست مرورگر)؛ کنتراست متن ≥ ۴٫۵.
- فوکوس همیشه دیده می‌شود (حلقهٔ ۲px)، زیر هدر چسبان نمی‌ماند (`scroll-padding`).
- دیالوگ بومی `<dialog>`: تله فوکوس، Esc، بازگردانی فوکوس.
- نمودار به‌تنهایی کافی نیست: خلاصهٔ متنی + جدول مقادیر.
- تایمر رزرو: صفحه‌خوان هر دقیقه و در ۳۰ و ۱۰ ثانیه، نه هر ثانیه.
- فرم: برچسب دائمی (نه فقط placeholder)، خطا با آیکون و متن، فوکوس به اولین خطا.
