# فونت‌ها

فایل‌های فونت در مخزن **نیستند** (مجوز و حجم). دو راه:

1. **گزینهٔ B (پیش‌فرض):** `next/font/google` با Vazirmatn (OFL). چیزی لازم نیست؛ بیلد فونت را دانلود و خودمیزبان می‌کند. در محیطی که دسترسی به fonts.googleapis.com ندارد، بیلد شکست می‌خورد؛ آنگاه گزینهٔ A.
2. **گزینهٔ A:** فایل‌های `woff2` فونت فارسی انتخابی (مثلاً Estedad با مجوز OFL) را اینجا بگذارید و در `next/fonts.ts` بلوک `localFont` را فعال کنید.

قبل از استفادهٔ تجاری، **مجوز دقیق همان نسخه‌ای که دانلود می‌کنید** را بخوانید. فقط زیرمجموعهٔ لازم (`arabic` + اعداد) را بارگذاری کنید و `display: swap` را نگه دارید.
