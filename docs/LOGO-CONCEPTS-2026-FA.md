# کانسپتهای لوگوی.newbie — Digital Shopping

چهار مسیر طراحی کاملاً متمایز برای لوگوی جدید فروشگاه دیجیتال. هر کانسپت شامل: فرم نماد، پالت رنگ، هالهٔ نور، تایپوگرافی و نحوهٔ اجرا در سایت است.

> تصاویر مرجع بصری در پوشهٔ `docs/logo-concepts/` قرار دارند.

---

## کانسپت A — «هستهٔ منشور» (Prism Core)

**ایده:** هستهای بلوری از لایههای شیشهای تو در تو که نماد «دقت، اصالت و شفافیت قیمت» است. دو حلقهٔ مداری نازک دور آن، حس تکنولوژی و داده را میدهد.

| عنصر | مشخصات |
|---|---|
| فرم | الماس چندوجهی (faceted core) + ۲ حلقهٔ مداری |
| پالت | Violet `#7C3AED` · Lavender `#C084FC` · Pink `#F0ABFC` · Night `#0B0716` |
| هاله | Nebula violet bloom، محیطی و نرم، با لبههای [`specular`] سفید |
| تایپوگرافی | sans هندسی با فاصلهٔ مثبت حروف؛ «Digital» ضخیم + «Shopping» سبک |
| مناسب برای | تم پیشفرض Nebula Violet — هماهنگی کامل با هویت فعلی |

**نقاط قوت:** لوکس، دیجیتال، بلافاصله قابل تشخیص در اندازهٔ کوچک (favicon).

---

## کانسپت B — «حلقهٔ نکسوس» (Nexus Loop)

**ایده:** دو روبان نوری درهمتنیده که هم نماد بینهایت و هم حرف D (Digital) را میسازند. نماد «اتصال، مقایسه و جریان خرید».

| عنصر | مشخصات |
|---|---|
| فرم | Infinity / monogram D از دو ribbon متقاطع |
| پالت | Cyan `#22D3EE` · Indigo `#6366F1` · Magenta `#A855F7` · Navy `#070B1A` |
| هاله | Aurora linear glow، انتقال رنگی از چپ به راست |
| تایپوگرافی | تکخطی مدرن (Mono/Geometric)، حروف یکدست |
| مناسب για | تم Ocean / Aurora — حس استارتاپی و مهندسی |

**نقاط قوت:**VERY ساده، پیشرو، چاپپذیر و قابل انیمیشن (چرخش نور دور حلقه).

## کانسپت C — «جرقهٔ کوانتوم» (Quantum Spark)

**ایده:** کیسهٔ خریدی که dengan مدار микروچیپ ترکیب شده و یک جرقهٔ نورانی از مرکز آن میجوشد. نماد «خرید هوشمند و فناوری».

| عنصر | مشخصات |
|---|---|
| فرم | Shopping bag + circuit traces + spark |
| پالت | Rose `#FB7185` · Pink `#F472B6` · Amber `#FBBF24` · Paper `#F5EFE6` |
| هاله | Rose-gold halo ذرهای (particle bloom) |
| تایپوگرافی | نیمه-serif گرم برای «Shopping» + sans برای «Digital» |
| مناسب برای | تم Rose / Solar — گرم، انسانی و جذاب |

**نقاط قوت:** تنها کانسپتی که حس «فروشگاه» را مستقیم منتقل میکند.

---

## کانسپت D — «سبد مداری» (Orbit Cart)

**ایده:** سبد خرید انتزاعی در مرکز سه حلقهٔ مداری با هستهای درخشان. نماد « جهانی بودن، ارسال و قیمت جهانی » (مخصوص محصولاتی مانند GTA VI Global Edition).

| عنصر | مشخصات |
|---|---|
| فرم | ۳ حلقهٔ متحدالمرکز + core درخشان + glyph سبد |
| پالت | Solar gold `#F59E0B` · Pale gold `#FDE68A` · Silver `#E2E8F0` · Space `#0A0A12` |
| هاله | Solar corona با لبهٔ نقرهای، تضاد بالا |
| تایپوگرافی | Sans کشیده با حروف بزرگ (Tracking بالا) |
| مناسب برای | تم Solar / Silver — حس پریمیوم و بینالمللی |

**نقاط قوت:** قابل تبدیل به loading animation (چرخش مدارها) و نماد «Global Edition».

## مراحل تصمیمگیری (پیشنهادی)

1. **فرم نماد:** A، B، C یا D — یا ترکیب دو کانسپت (مثلاً A+B).
2. **پالت:** Violet / Aurora / Rose / Solar / Silver — یا پالت سفارشی trash.
3. **الگوی هاله:** Nebula محیطی · Aurora خطی · Corona خورشیدی · Particle ذرهای · بدون هاله (مینیمال).
4. **محل اعمال:** فقط هدر · هدر + فوتر · فاویکن و PWA · تمام تمها با تغییر رنگ هاله.
5. **تایپوگرافی:** ضخیم+سبک (.dumps) · تکخطی مدرن · نیمه-serif گرم · کشیده لوکس.
6. **انیمیشن:** ثابت · چرخش مدار · تنفس نور · شارژ هنگام بارگذاری.

پس از انتخاب، لوگوی نهایی بهصورت **SVG خالص + CSS variables** پیاده میشود تا با ۶ تم کهکشانی هماهنگ شود و در تمام اندازهها تیز بماند.
