# پیشنهادهای منو و لوگوی بالای صفحه

پیشنمایش بصری زنده: `docs/header-logo-concepts.html` (در مرورگر باز است).

## منوها
1. **Pill Navigation** — آیتمهای کپسولی، پُرشدگی نورانی، مدرن و واضح.
2. **Glass Dock** — داک شیشهای با گرادینت نور، جلوهٔ پریمیوم.
3. **Laser Underline** — خط لیزری درخشان زیر آیتم فعال، مینیمال و لوکس.
4. **Neon Serif** — تایپوگرافی درخشان، حس برند لوکس.
5. **Mega Cards** — کارتهای شبکهای با نور درونی، مناسب دستهبندیها.

## لوگوها
1. **Diamond Halo** — الماس چرخاندهشده با هالهٔ دو رنگ.
2. **Orbit Ring** — حلقهٔ مداری سهبعدی با انعکاس.
3. **Serif Monogram** — مونوگرام DS با سایه و نور.
4. **Prism Gem** — الماس شیشهای گرادینتی.
5. **Holographic Bevel** — لوگوی هولوگرافیک با لبه و سایهٔ رنگی.

تم پیشفرض پروژه **Nebula Violet** است؛ تمام نمونهها با پالت تم هماهنگاند.

**انتخاب کاربر (اعمال شد):** منوی ترکیبی **Pill Navigation + Glass Dock + Neon Serif** (کپسولها در داک شیشهای، آیتم فعال با تایپوگرافی سریف و درخشش نئون) و لوگوی **Diamond Halo** (الماس سهبعدی با هاله و انعکاس).
