## ۲٫ نحوهٔ اعمال فنی (پس از تأیید شما)

1. منبع حقیقت اصلی `packages/ui/src/tokens/tokens.ts` است؛ پالتها بهعنوان `THEMES` اضافه و توسط
   `npm run tokens:build` به `styles/tokens.css` تولید میشوند (فایل CSS دستی ویرایش نمیشود).
2. تمها از طریق `data-theme="<name>"` روی `:root` اعمال میشوند؛
   `packages/ui/src/lib/theme.ts` از سهحالتهٔ فعلی (light/dark/system) به تمهای نامدار گسترش مییابد.
3. دکمهٔ تم در `apps/web/components/theme-toggle.tsx` به چرخش میان تمهای انتخابشده تبدیل و
   `themeInitScript` پیش از نقاشی، تم ذخیرهشده را اعمال میکند (بدون پرش رنگی).
4. تمام جفتهای رنگی توسط `npm run contrast` در CI بررسی میشوند؛
   تمهای تاریک نیازمند `--signal-ink` و `--brand-ink` تیرهاند (در جدول بالا لحاظ شدهاند).
5. `docs/DESIGN-LANGUAGE.md` با پالت انتخابشده بهروز میشود.

## ۳٫ نکاتی که قبل از انتخاب باید بدانید

- تغییر تم فقط توکنهاست؛ کامپوننتها، RTL، اعداد فارسی و ساختار صفحات دستخورده باقی میمانند.
- تمهای تیرهٔ شب مخملی و بنفش شبانه هزینهٔ اضافی بارگذاری فونت ندارند.
- در تم مونوکروم صنعتی گوشهها ۰px میشود؛ این تنها تمی است که از قاعدهٔ ۲px عدول میکند
  (با کسب اجازهٔ شما).
- میتوانیم ترکیبی بسازیم: تم روشن پیشفرض + تم تیرهٔ جداگانه (مثلاً کاغذ گرم + شب مخملی)
  تا کاربر تنها یک دکمهٔ روز/شب ببیند.
